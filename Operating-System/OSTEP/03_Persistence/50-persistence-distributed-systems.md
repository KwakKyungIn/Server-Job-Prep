# 🌐 분산 시스템 — OSTEP Chapter 50

이 장에서는 **분산 시스템(Distributed System)** 의 핵심 개념을 다룬다.  
분산 시스템은 여러 대의 기계가 협력하여 하나의 서비스를 제공하는 구조이며,  
특히 **실패를 견디는 설계**, **신뢰할 수 없는 통신 처리**, **RPC 기반의 통신 추상화** 등이 핵심 주제다.

---

## ❓ 핵심 질문

> 분산 시스템에서는 네트워크 오류, 서버 고장 등 **빈번한 실패**가 발생한다.  
> 그렇다면 어떻게 시스템 구성 요소들이 **고장나더라도 동작을 멈추지 않는 시스템**을 만들 수 있을까?

---

## 🔍 상세 개념 정리

### 50.1 통신의 기본

#### 📌 핵심 개념

- 분산 시스템은 **여러 기계가 네트워크를 통해 연결되어 있는 시스템**이다.
- 하지만 **네트워크는 본질적으로 신뢰할 수 없다.**
    - 패킷은 손실될 수 있고
    - 손상되거나
    - 아예 목적지에 도달하지 못할 수 있음
- 통신 계층의 오류는 다음과 같은 요인에서 발생한다:
    - 전송 중 비트 반전
    - 링크 손상
    - 라우터 또는 호스트의 버퍼 오버플로우
    - 네트워크 분리(연결 끊김)

#### 📎 핵심 메시지

> 최신 네트워킹에서도 패킷 손실, 지연, 순서 뒤바뀜은 흔하다.  
> 따라서 **애초에 완벽한 통신을 가정해서는 안 된다.**

---

### 50.2 신뢰할 수 없는 통신 계층

#### 📌 UDP 계층의 예

- **UDP (User Datagram Protocol)** 은 신뢰성을 보장하지 않음
    - 메시지를 보낸다고 해도 도착을 보장하지 않음
    - 순서도 유지되지 않음
    - 중복 메시지 가능성 존재

#### ✅ 예시 코드: UDP 소켓 통신
간단한 UDP 클라이언트/서버 코드는 그림 50.1과 50.2에서 확인 가능

#### 📎 요점 정리

- 신뢰할 수 없는 통신 계층은 단순하지만,
- 신뢰성은 **상위 계층에서 직접 구현해야 함** (앱에서 처리)

---

### 50.3 신뢰할 수 있는 통신 계층

#### 📌 목표

- **패킷 손실을 감지하고 자동 재전송하여** 통신의 신뢰성을 확보하는 것

#### ✅ 핵심 기술 요소

1. **확인 응답 (ACK)**  
   - 수신자가 메시지를 잘 받았다는 확인을 전송

2. **타임아웃 및 재시도**
   - ACK를 일정 시간 안에 받지 못하면 재전송
   - 전송자는 이전 메시지의 사본을 유지해야 함

#### 📎 문제점

- **중복 전송** 가능성 → **순번 번호(sequence number)** 로 해결
- **성능 저하** 가능성 → 불필요한 재전송/대기 증가

---

### 50.4 통신 추상화

#### 📌 통신 계층의 상위 추상화

- **분산 공유 메모리(DSM)**: 여러 시스템에서 하나의 가상 주소 공간을 공유
- **RPC (Remote Procedure Call)**: 다른 기계의 함수를 로컬처럼 호출

#### ✅ 분산 공유 메모리 (DSM)

- 페이지가 없으면 원격 요청으로 가져오기 (페이지 폴트 핸들링)
- 마치 멀티 쓰레드처럼 동작하지만, 실제로는 **다른 기계**에서 실행됨

---

### 50.5 RPC: Remote Procedure Call

#### 📌 RPC의 작동 원리

- 클라이언트는 **로컬 함수를 호출하듯이** 서버의 함수 호출
- 내부적으로는 다음 절차가 수행됨:

1. **인터페이스 정의**
2. **클라이언트 스텁 생성**
3. **인자 직렬화 (Marshalling)**
4. **요청 전송**
5. **서버 응답 대기**
6. **응답 수신 후 복원 (Unmarshalling)**

#### ✅ RPC 코드 흐름 요약

```c
// 클라이언트
result = remote_function(arg1, arg2);
```

- `remote_function()`은 실제 서버에 메시지를 보내고 응답을 기다리는 스텁 함수

#### 📎 주의 사항

- 대부분의 RPC는 **동기적** (결과 받을 때까지 블로킹)
- 일부는 **비동기적** 호출도 지원

---

## 🔍 상세 개념 정리 (계속)

### 50.6 요약

- 분산 시스템의 핵심은 **불안정한 통신 환경에서도 신뢰성을 확보하는 것**
- 이를 위해 **다양한 계층의 추상화와 복구 메커니즘**이 필요하다
- RPC나 DSM 같은 상위 추상화는 개발을 단순하게 만들지만, **오류 감지·복구에 매우 신중해야 함**

---

## ✅ 최종 요약

| 주제 | 설명 |
|------|------|
| 통신 오류 | 패킷 손실, 순서 뒤바뀜, 중복 발생 가능 |
| 신뢰할 수 없는 계층 | UDP 같은 프로토콜은 도착·순서를 보장하지 않음 |

| RPC | 원격 함수 호출을 로컬처럼 표현하는 방식 |
| 실무 고려사항 | 동기/비동기 여부, 오류 처리, 실패 감지 등 |
