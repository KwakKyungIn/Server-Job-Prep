# 📚 STL List 정리

C++의 `std::list`는 **연결 리스트(linked list)** 구조를 사용하는 컨테이너입니다.  
원소들이 **노드(Node)** 단위로 메모리에 분산되어 있으며, 각 노드는 다음/이전 노드를 가리키는 포인터를 가지고 있어  
**중간 삽입/삭제에 유리한 구조**를 가집니다.

---

## ✅ 기본 개념

| 항목 | 설명 |
|------|------|
| 구조 | 연결 리스트 (Linked List) |
| 저장 방식 | **연속된 메모리 아님**, 노드마다 포인터로 연결 |
| 메모리 | 각 노드마다 포인터 1~2개 포함 (단일/이중) |
| 삽입/삭제 | **중간/처음/끝** 모두 빠름 |
| 접근 속도 | 임의 접근(Random Access) 불가, 순차 접근만 가능 |

---

## 🔄 연결 리스트의 종류

| 종류 | 특징 |
|------|------|
| 단일 연결 리스트 (Singly Linked List) | `next` 포인터만 존재 |
| 이중 연결 리스트 (Doubly Linked List) | `prev`, `next` 두 포인터 보유 |
| 원형 연결 리스트 (Circular List) | 마지막 노드가 처음 노드를 가리킴 |

> C++ STL의 `std::list`는 **이중 연결 리스트**입니다.

---

## ⚙️ 동작 원리

- 각 요소는 노드(Node)로 존재하며 `prev`, `next` 포인터를 통해 서로 연결됩니다.
- 내부 구조는 다음과 같습니다:

```
[Head] <-> [Node1] <-> [Node2] <-> ... <-> [Tail]
```

- 새 노드를 삽입할 때: 포인터만 조정하면 되므로 **O(1)**
- 노드를 삭제할 때: 역시 포인터만 조정하면 되므로 **O(1)**
- 특정 위치 찾기: 반복자를 따라 순차 탐색 → **O(n)**

---

## 📌 장단점 정리

| 항목 | `std::vector` | `std::list` |
|------|---------------|-------------|
| 삽입 (중간) | ❌ 느림 (O(n)) | ✅ 빠름 (O(1)) |
| 삭제 (중간) | ❌ 느림 (O(n)) | ✅ 빠름 (O(1)) |
| 접근 (임의) | ✅ 빠름 (O(1)) | ❌ 느림 (O(n)) |
| 메모리 효율 | ✅ 연속된 공간 | ❌ 포인터 오버헤드 |
| 캐시 성능 | ✅ 좋음 | ❌ 나쁨 (비연속 메모리) |

---

## 🔁 주요 메서드 예시

```cpp
#include <list>
#include <iostream>

int main() {
    std::list<int> myList;

    // push front / back
    myList.push_back(10);
    myList.push_front(5);

    // 삽입 (중간)
    auto it = myList.begin();
    ++it; // 두 번째 위치
    myList.insert(it, 7); // 5, 7, 10

    // 삭제
    myList.erase(it); // 5, 10

    // 순회
    for (int n : myList) {
        std::cout << n << " ";
    }
}
```

---

## 🧠 STL List를 써야 하는 상황

- **중간 삽입/삭제가 자주 일어날 때**
- **데이터의 순서 유지가 필요할 때**
- **객체 수가 자주 변동할 때 (ex. 몬스터 목록, 클라이언트 연결 목록 등)**

---

## ⚠️ 주의할 점

- **임의 접근이 안된다.**  
  `myList[2]`처럼 직접 인덱스로 접근할 수 없음. 대신 반복자 사용 필요

- **포인터 오버헤드**  
  각 노드가 포인터 2개(`prev`, `next`)를 가지므로, **메모리 사용량이 크고 캐시 효율이 떨어짐**

---

## 💬 게임 서버에서 예시

```cpp
std::list<Player*> playerList;

// 접속한 유저 추가
playerList.push_back(new Player(...));

// 게임 도중 퇴장한 유저 제거
for (auto it = playerList.begin(); it != playerList.end(); ) {
    if ((*it)->IsDisconnected()) {
        delete *it;
        it = playerList.erase(it);
    } else {
        ++it;
    }
}
```

- 동적으로 변하는 객체 관리에 적합
- 삭제 중 `++it` 순서에 주의해야 함

---

## ✅ 요약 정리

| 특징 | 설명 |
|------|------|
| 메모리 구조 | 포인터로 연결된 노드 구조 (비연속적) |
| 삽입/삭제 | **O(1)** (반복자만 알고 있으면 어디서든) |
| 임의 접근 | ❌ 느림. `it + n` 불가 |
| 사용 적합 예시 | 중간 삭제 많은 큐, 유저 목록, 채팅 메시지 버퍼 등 |
| 잘못된 사용 예 | 정렬된 대량 데이터를 자주 검색해야 하는 경우 (vector가 낫다) |

---

> STL `list`는 상황에 따라 굉장히 유용하지만, **항상 vector보다 낫지는 않다.**  
> 자신이 원하는 **삽입/삭제/접근 특성**을 정확히 파악하고 선택해야 한다.
