# 📦 STL Vector (심화편)

> `std::vector`는 C++ STL의 대표적인 **동적 배열 컨테이너**이다.  
> 이번 정리에서는 vector의 **물리적 구조**, **삽입/삭제 성능**, **자주 발생하는 오류**를 중심으로 다룬다.

---

## 🔍 vector는 결국 배열이다

- `std::vector`는 **동적으로 크기가 조절되는 배열**이다.
- 내부적으로 **단일 연속 메모리 블록**에 데이터를 저장한다.
- 이 때문에 다음과 같은 특징이 있다:

| 특징 | 설명 |
|------|------|
| ✅ 빠른 임의 접근 | `v[i]`, `v.at(i)` → O(1) 시간 |
| ❌ 중간 삽입/삭제 느림 | 뒤 원소들을 모두 밀거나 당겨야 함 |
| ✅ 마지막 삽입/삭제 빠름 | `push_back()`, `pop_back()`은 O(1) |

---

## ⚙️ 삽입/삭제 성능 비교

| 위치 | 삽입/삭제 성능 | 이유 |
|------|----------------|------|
| 맨 앞 (`begin()`) | ❌ 매우 느림 (O(n)) | 모든 원소를 뒤로 shift |
| 중간 (`v.begin() + i`) | ❌ 느림 (O(n)) | i 이후 원소 전부 이동 |
| 맨 뒤 (`end()`) | ✅ 빠름 (O(1)) | 위치 고정, shift 불필요 |

### 📌 예시

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};

// 맨 앞 삽입 (비효율적)
v.insert(v.begin(), 0);  // 모든 원소 이동

// 맨 뒤 삽입 (효율적)
v.push_back(6);  // 단순 추가
```

---

## 🧠 연속된 메모리란?

- `std::vector`는 원소가 **하나의 메모리 블록에 연속**적으로 저장됨
- 이 때문에 **포인터 연산**, **임의 접근(indexing)** 이 가능

```cpp
std::vector<int> v = {10, 20, 30};
std::cout << *(v.data() + 1);  // 20 출력
```

- `v.data()`는 배열처럼 내부 메모리 주소를 반환한다.

---

## 🧨 자주 발생하는 실수: 반복자 무효화

### 🔥 실수 예시

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};

for (std::vector<int>::iterator it = v.begin(); it != v.end(); ++it) {
    int data = *it;
    if (data == 3) {
        v.erase(it);  // 🚫 위험한 코드!
    }
}
```

- `erase()`는 해당 요소를 삭제하고 **남은 원소들을 앞으로 당기며**,  
  동시에 **삭제된 위치의 반복자를 무효화**시킨다.
- 위 코드에서는 `it`가 무효화된 상태에서 `++it`가 호출되어 **미정의 동작(UB)** 발생.

---

### ✅ 안전한 반복자 삭제 방법

```cpp
for (auto it = v.begin(); it != v.end(); ) {
    if (*it == 3) {
        it = v.erase(it);  // 삭제 후 다음 유효한 반복자 반환
    } else {
        ++it;
    }
}
```

- `erase()`는 **삭제된 위치 다음 원소를 가리키는 반복자**를 반환하므로,
  그걸 다시 `it`에 대입해 반복문을 안전하게 이어간다.

---

## 💡 실전 팁

- 반복자 연산이 포함된 루프에서는 **반복자 무효화 여부**를 반드시 검토하자
- `erase()`는 **하나의 원소를 제거**하면서 남은 원소들을 **앞으로 이동**시키기 때문에,  
  **성능 저하**도 발생할 수 있고 **반복자 무효화**도 유발한다
- 반복자 무효화가 자주 발생한다면 `list`, `deque` 같은 컨테이너 사용을 고려할 것

---

## ✅ 요약

| 항목 | 요약 |
|------|------|
| 메모리 구조 | 원소가 연속된 블록에 저장되는 배열 구조 |
| 삽입/삭제 성능 | 맨 뒤는 빠르지만, 중간/앞은 느림 (O(n)) |
| 반복자 무효화 | `erase()` 호출 시 해당 위치 이후 반복자 무효화됨 |
| 안전한 삭제 | `it = v.erase(it)` 형태로 다음 반복자 재할당 필요 |
| 면접 포인트 | vector의 물리 구조와 iterator 무효화에 대한 이해 |

---

> 🧭 STL vector는 매우 유용한 컨테이너지만, 내부 구조를 이해하지 못하면  
> 반복자 무효화와 비효율적인 연산으로 **버그와 성능 문제**를 초래할 수 있다.
